# Royal Barber Shirley — Complete Static Website

Standalone multi-page concept site built in HTML, CSS and vanilla JavaScript.

## Pages
- index.html
- services.html
- about.html
- gallery.html
- reviews.html
- faq.html
- booking.html
- contact.html
- privacy.html
- terms.html
- accessibility.html
- 404.html

## Before a real launch
1. Get written approval from the business.
2. Replace concept SVGs with approved real photography.
3. Replace placeholder reviews with genuine, verified reviews.
4. Confirm current services, prices, opening hours, contact email and address.
5. Update sitemap/robots with the final domain.
6. Configure real email/form handling if needed.
7. Add analytics/cookies only after updating the privacy/cookie setup.

Open `index.html` locally or upload the whole folder to any static host.
